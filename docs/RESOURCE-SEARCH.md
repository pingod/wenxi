# 资源搜索

入口位于「解析」页，保留原有四个主导航。资源搜索查询服务器聚合的公开分享；「网盘」里的文件搜索继续查询当前账号和目录。

## 使用流程

输入关键词并提交 → 逐批显示分享 → 点击「打开」→ 解析原分享、浏览文件列表 → 点击文件准备预览或播放 → 请求后端号池转存 → 定位新分享中的对应文件 → 继续预览或播放。搜索、打开分享和浏览目录都不会请求转存。提取码独立传递到已有解析流程，打开文件列表后返回可继续查看搜索结果。磁力与种子结果复用已有 BT 流程；暂不支持解析的链接可以复制或用浏览器打开。

预览准备期间可返回文件列表，客户端取消请求并忽略晚到的响应。转存失败、账号不可用或新分享内无法唯一定位文件时，提供「重试」和「使用原链接预览」。App 提交选中文件 ID、来源父目录、名称和大小；后端使用该分享自己的凭据验证文件，提交保存任务时只包含这一个文件。目录、信息变化、无法定位和缺少文件类型的响应都会停止转存，不会退回整个目录或原分享。

新分享根目录必须只包含一个普通文件，使用新的文件 ID 和新分享提取码；继续核对可用的大小与哈希，不会沿用旧分享的文件 ID 或提取码。允许网盘因同名文件自动更名。同一次分享浏览中按选中文件分别缓存十分钟，最多保留 64 个成功结果；预览其他文件需要单独申请转存，不会提前转存同目录文件。新分享只包含本次文件，因此播放列表也只包含该文件，其他文件可返回原列表再打开。

夸克、UC、百度、阿里、迅雷、移动的现有适配器支持从分享子目录选择文件。光鸭、悟空的旧后端适配器暂缺经过确认的子目录读取协议，子目录预览明确提示使用原链接，不转存整个目录；根目录中可确认的普通文件仍可单独转存。所有平台的真实在线可用性仍取决于账号、网盘接口和分享状态。

退出预览后的临时转存清理在后台静默执行，文件列表不显示清理进度条；清理失败会保留记录以便后续重试。

界面采用网页当前 Classic 主题的交互：网盘分类和数量、结果统计、折叠筛选、紧凑分隔列表、每批 15 条滚动显示。手机横向滑动网盘分类，桌面横排分类；搜索栏随列表滚动，长列表可一键回到顶部。保留应用的主题配色和原生导航。

每条结果展示标题、网盘、链接、来源、日期和提取码（有数据时），链接旁异步显示本机测活状态。点击结果正文查看完整标题、说明、链接和检测说明，可点击「重新检测」跳过本机缓存；右侧直接打开或复制。「可解析」分类表示应用支持该分享类型，测活状态单独表示当前用户网络看到的分享可访问性。

## 本机自动测活

检测规则随 App 内置，用户设备通过当前网络直接请求网盘官方公开分享接口。测活使用独立的匿名 HTTP 客户端，支持既有 Windows 系统代理；不请求聚合服务器的测活接口、不需要 Key，也不使用账号池或已登录账号的 Cookie。网盘临时分享凭据仅用于本次只读检测，不落盘。搜索仍使用既有聚合服务，文件预览的号池转存流程保持独立。

结果先显示，再对真实可见行进行检测；180 毫秒滚动防抖，最多三条并发。滑出视口、切换筛选、新搜索、切到后台或离开页面时取消旧请求，并忽略晚到结果。只读接口最多查询第一页的少量文件，不下载文件、不创建目录、不转存、不生成分享。有效状态不保证所有子目录或文件都可下载。

| 内置规则 | 读取内容 |
| --- | --- |
| 夸克、UC | 分享访问令牌和第一页文件列表 |
| 百度 | 原提取码验证（有提取码时）和公开分享列表 |
| 阿里云盘 | 分享令牌和文件列表；快传读取匿名预览列表 |
| 123 网盘 | 公开分享第一页，校验原提取码、过期状态 |
| 天翼云盘 | 分享信息、访问码校验 |
| 115 网盘 | 分享快照；缺提取码时直接提示待确认 |
| 光鸭云盘 | 分享访问凭据和第一页文件列表 |
| 迅雷网盘 | 公开分享状态和文件列表 |
| 中国移动云盘 | 匿名分享文件列表，复用已有协议编码 |
| 中国联通云盘 | 官方短链解析和公开分享文件信息，复用已有协议编码 |

状态为：待检测、检测中、链接有效、链接失效、提取码待确认、暂无法确认、暂不支持检测。只有网盘明确返回分享取消/过期/删除，或成功返回空文件列表，才判为失效。验证码、登录限制、限流、超时、网络异常、通用 HTTP 404、缺字段和未知响应不作为失效依据；普通 HTML 或仅包含网盘名称的页面也不作为有效依据。115、迅雷等平台可能限制匿名访问，此时显示「暂无法确认」。磁力、种子及尚未内置规则的平台不发送探测请求。

缓存仅在内存中保存，按分享身份和原提取码区分：有效十分钟、失效三分钟、不支持三十分钟，其余一分钟，最多 1200 条。手动重测移除本机缓存后重新直连；单个平台限流后冷却一分钟，其他平台继续检测。每条分享总预算十六秒、每次请求六秒，流式接收限制为 128 KiB；请求不会自动重放。测活不会删除、重排或禁止打开搜索结果，避免临时状态影响用户选择。协议变化需要更新 App 中的规则。

高级筛选支持包含词（标题须全部包含）、排除词（含任一词即排除）和优先可解析。筛选不区分大小写，在本次结果内完成，不触发新搜索。网盘分类的数量为完整接收结果中各网盘的数量，结果统计为当前筛选后的数量。关键词历史保存在既有的本地加密状态中，可清空。完成的查询在内存缓存两分钟；「重新搜索」跳过客户端缓存。新查询、停止搜索和离开页面都会取消旧连接，失败时保留部分结果。

## 接口

- 默认服务：`http://111.91.22.90:5004`，由 `RESOURCE_SEARCH_URL` 编译参数覆盖。
- 首选：`GET /api/v1/search/stream?keyword=...&scope=all&limit=1000&format=object`。
- 兼容：流式接口不存在或不支持 SSE 时，使用 `/api/v1/search`。普通网络中断或限流不会自动再提交一次查询。
- 只使用公开查询接口，不携带后台管理员凭据、面板 Key 或转存管理密钥。
- 对支持号池的平台，搜索对象返回 `pool_supported` 和有效期一小时的 `open_ticket`。点击文件预览时调用 `POST /api/v1/search/open/file`，请求体为 `{ "ticket": "...", "selection": { "file_id": "...", "parent_id": "...", "name": "lesson.mp4", "size": 123 } }`，不提交源链接、提取码、网盘访问令牌或用户账号凭据。票据过期时需重新搜索。
- 转存接口返回 `data.url`、新分享自己的 `data.password`、`mode`、`reused`；成功时还必须有 `transfer_scope: "file"` 和对应的 `source_file_id`。`temp_share` 与 `pool_share` 表示可用的号池分享，`original` 表示未完成转存并带有 `reason`、`message`。客户端不会将原链接、未确认单文件范围或文件 ID 不匹配的响应当作成功。
- 单文件转存使用独立路径。旧服务端返回 404/405 时提示更新，不回退 `/search/open`；新服务端对旧客户端只带票据的请求返回 400，避免静默转存整个分享。前后端需要配套更新。
- 转存请求只发送一次，不自动重试，等待预算为九十秒。后台继续控制网盘开关和账号池；App 预览独立于网页复制或查看模式。
- `initial`、`update` 按分享身份合并；`complete` 使用最终结果顺序，并保留已补全的提取码。兼容旧版本数组结果。
- 返回的是分享链接，不是下载直链。文件、账号和下载规则由已有解析流程处理。
- 移除旧客户端 60 条上限，最多请求和保留 1000 条；服务端限制仍可能降低返回条数。每批 15 条为本地显示批次，滚动加载不会再次请求服务端，也不代表存在服务端游标分页。

传输层复用既有 Dio 客户端与 Windows 系统代理适配，使用逐块 UTF-8 和 SSE 帧解析。空闲接收超时为 40 秒，单次搜索总预算为 70 秒，最大接收内容为 4 MiB。

## 实现位置

- `lib/domain/resource_search.dart`：公开分享模型、兼容格式、去重和提取码合并。
- `lib/data/resource_search_api.dart`：SSE、取消、错误和 JSON 兼容。
- `lib/data/resource_search.dart`：搜索状态、缓存、筛选和历史。
- `lib/data/resource_link_checks.dart`：测活状态、视口队列、取消、缓存和各网盘冷却。
- `lib/data/resource_link_probe.dart`：内置直连规则，独立匿名客户端、超时与响应大小限制。
- `lib/data/resource_pool_preview.dart`：仅在文件预览时转存、解析新分享及定位对应文件。
- `lib/ui/resource_search_page.dart`：原生搜索界面与入口组件。
- `lib/ui/parse_page.dart`：调用已有解析流程。
- `lib/ui/browser_page.dart` 与 `lib/ui/preview_page.dart`：浏览时保留原分享，进入预览后才准备号池分享。

界面沿用应用主题，适配手机、桌面、深色模式、大字体与横屏。截图及测活界面用例在 `test/resource_search_widget_test.dart`，搜索协议与状态测试在 `test/resource_search_test.dart` 和 `test/resource_search_http_test.dart`。测活规则、队列与实际 HTTP 取消/超时测试分别在 `test/resource_link_probe_test.dart`、`test/resource_link_checks_test.dart`、`test/resource_link_probe_http_test.dart`；协议响应使用固定样例，HTTP 测试使用本机测试服务，不依赖真实用户分享或网盘账号。

`tool/capture_resource_pages_test.dart` 可渲染真实应用路由的安卓和 Windows 独立图片；`test/fixtures/resource_search_samples.dart` 提供 24 条虚构样例，仅用于布局检查。通过 `--dart-define=UI_RENDER_OUTPUT=<绝对目录>` 指定图片输出位置。
